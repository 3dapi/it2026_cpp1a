# Parcel Factory

C++와 `glc2d_lib`를 사용해 제작하는 2D 택배 분류 아케이드 게임

---

## 1. 프로젝트 정보

| 항목    | 내용                            |
| ----- | ----------------------------- |
| 프로젝트명 | Parcel Factory                |
| 장르    | 2D 아케이드 / 타임어택                |
| 개발 환경 | C++, Visual Studio, glc2d_lib |
| 개발 기간 | 5주                            |
| 개발 인원 | 1명                            |

---

## 2. 게임 소개

플레이어가 물류센터 직원이 되어
컨베이어 벨트를 통해 들어오는 택배를 **알맞은 배송 구역으로 분류하는 게임**이다.

택배마다 색상 또는 표시를 통해 배송지가 정해져 있으며,
플레이어는 제한 시간 동안 최대한 많은 택배를 정확하게 분류해야 한다.

게임이 진행될수록 택배가 등장하는 속도가 빨라지고
새로운 종류의 택배가 추가되면서 난이도가 점점 증가한다.

---

## 3. 게임 목표

제한 시간 동안 택배를 올바른 배송 구역으로 분류하여
**목표 점수 이상을 획득하는 것**이 게임의 목표이다.

* 올바른 구역에 분류 → 점수 획득
* 연속으로 정확하게 분류 → 콤보 증가
* 잘못된 구역에 분류 → 점수 감소
* 택배를 놓침 → 콤보 초기화

---

## 4. 게임 진행 흐름

```text
택배 생성
   ↓
컨베이어 벨트를 따라 이동
   ↓
택배 종류 확인
   ↓
플레이어가 택배 집기
   ↓
알맞은 배송 구역으로 이동
   ↓
택배 분류
   ↓
점수 / 콤보 획득
   ↓
다음 택배 처리
```

---

## 5. 핵심 시스템

### 플레이어

* 방향키 또는 WASD를 이용해 이동
* Space바를 활용하여택배를 집거나 내려놓을 수 있음
* 대형 택배를 들 경우 모종의 패널티 부여

### 택배

* 일정 시간마다 랜덤으로 생성
* 컨베이어 벨트를 따라 자동으로 이동
* 종류에 따라 이동해야 하는 배송 구역이 다름

### 배송 구역

택배의 종류에 따라 지정된 구역에 분류해야 한다.

| 택배 종류    | 배송 구역 |
| -------- | ----- |
| 🔴 빨간 택배 | A 구역  |
| 🔵 파란 택배 | B 구역  |
| 🟡 노란 택배 | C 구역  |
| 🟢 초록 택배 | D 구역  |

---

## 6. 특수 택배

게임이 진행되면 일반 택배 외에 특수 택배가 등장한다.

### ⚡ 긴급 택배

일정 시간 안에 분류해야 하는 택배.

### ⚠️ 취급주의 택배

잘못 분류하면 일반 택배보다 큰 감점이 발생한다.

### 📦 대형 택배

들고 있는 동안 플레이어의 이동 속도가 감소한다.

---

## 7. 점수 시스템

택배를 정확하게 분류하면 기본 점수를 획득한다.

연속으로 정확하게 분류할 경우 **콤보**가 증가하며
높은 콤보를 유지할수록 추가 점수를 얻을 수 있다.

```text
정확한 분류
   ↓
콤보 증가
   ↓
추가 점수 획득
```

잘못된 분류 또는 택배를 놓치면 콤보가 초기화된다.

---

## 8. 난이도 증가

게임 시간이 지날수록 점점 어려워진다.

* 택배 생성 속도 증가
* 컨베이어 벨트 속도 증가
* 택배 종류 증가
* 동시에 등장하는 택배 증가
* 특수 택배 등장

초반에는 기본적인 택배 분류에 집중하고,
후반에는 빠른 판단과 정확한 이동이 필요하도록 구성한다.

## 9. 조작 방법

| 키            | 기능           |
| ------------ | ------------ |
| `WASD` / 방향키 | 플레이어 이동      |
| `Space`      | 택배 집기 / 내려놓기 |
| `ESC`        | 일시정지         |

---

## 10. 게임 종료

제한 시간이 끝나면 게임이 종료되고 최종 점수를 표시한다.

```text
목표 점수 달성
→ Stage Clear

목표 점수 미달
→ Game Over
```
